# SECURITY.md

Security contact
----------------

This project is custody-related and security-sensitive. Do NOT open public issues to report exploitable vulnerabilities.

If you have discovered a security issue that may impact custody, follow private disclosure:

- Reporting channel: REPLACE_WITH_PRIVATE_CONTACT (email or secure disclosure URL)
- PGP/GPG key (optional): REPLACE_WITH_KEY

Do NOT send private keys, mnemonics, seed phrases, real funds, or production credentials to the project team. If you must share sensitive evidence, redact or share via an approved secure channel.

Scope and policy
----------------

- This repository is not audited, not production-ready, and MUST NOT be used with mainnet or real funds.
- We will not accept PoC exploit code that signs or sends transactions to mainnet. Provide non-executing repro steps, test vectors, or minimal snippets that reproduce the issue offline.
- Response expectations: triage acknowledgement within 7 business days; public disclosure coordinated after mitigation.

What to include in a report
--------------------------

- Affected component (file, program, commit SHA)
- A concise description of the issue and impact
- Steps to reproduce (without exposing secrets)
- Suggested mitigation if available
- Contact method for follow-up (PGP key or secure channel)

Legal
-----

This project welcomes responsible disclosure. Do not attempt exploitative actions against deployed infrastructure or third parties. Maintain privacy of any user data you might encounter.
